# Kasir Warung (demo tampilan)

Demo tampilan kasir warung makan: antrean nota, grid menu berikon, nota aktif, lembar bayar + kembalian, rekap harian.
Satu file `index.html`, tanpa CDN/font internet (jalan offline). Data hanya contoh.

Bagian: Kasir (`#kasir`), Rekap (`#rekap`).

Demo: https://editorzash.github.io/demo_kasir_warung/
